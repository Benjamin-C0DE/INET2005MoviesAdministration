MoviesAdmin is the administration section for the largerer movie web application, inspired by sites like Rotten Tomatoes. 
This app provides the core tools for managing all movie data 
This includings: creating, editing, viewing, and deleting movie records stored in a SQL Server database.

This admin component forms the foundation for the project. 
The MoviesAdmin project ensures the system begins with managed movie information that the rest of the platform relies on.
